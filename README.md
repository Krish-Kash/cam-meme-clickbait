# 🛡️ Cyber or Chill? — CAM 2026 Meme Quiz

A cybersecurity awareness meme quiz game for **Cybersecurity Awareness Month 2026** — Meme & Chill Thursday Edition.

## 🎮 Features

- **15 cybersecurity scenarios** across phishing, passwords, social engineering, malware, and network security
- **Meme-powered reactions** for correct and incorrect answers
- **Combo streaks & time bonuses** — the faster and more consistently you answer, the higher your score
- **Rank system** — from Script Kiddie to CISO Material
- **Local leaderboard** — compete with your teammates
- **Copy-to-Slack** — share your score with one click
- **Cyberpunk aesthetic** — scanlines, neon glow, matrix rain background

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## 📦 Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Krish-Kash/cam-meme-clickbait)

Or deploy manually:

```bash
npm run build
npm start
```
